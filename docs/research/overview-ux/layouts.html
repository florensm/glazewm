Three ways to spread windows

The same windows in the same room, laid out as GlazeWM's cluster (where they sit on screen, kept), GNOME's rows, and an even grid like Windows Task View. Switch layouts to watch the windows move; the numbers are each window's final scale.

Each window's final scale

Its width in the overview over its width on screen. The largest of the three is green.

Cluster

One scale for every window, each where it sits relative to the others, so the eye finds them where it left them and the big window stays the big one. Its cost is the bounding box: one far-off window shrinks everything.

Rows

GNOME's: rows by height, short windows bumped up to 1.5×. With equal tiles it uses the room best (six tiles at 0.81× against the cluster's 0.65×). With mixed sizes it evens them out, shrinking the big window most.

Grid

Each window fills an even cell in reading order. The best average, because small windows grow up to the cap, but the big window you were working in shrinks the most, and positions are lost.
